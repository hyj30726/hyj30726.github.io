# 마음의 작은 섬

대학생이 마음을 돌아보고 잠시 쉬어갈 수 있는 정적 웹페이지입니다.
메인 주소 <https://hyj30726.github.io/> 에서 마음의 작은 섬으로 이동합니다.

## 파일

- `index.html` — 메인 주소에서 마음의 작은 섬으로 이동하는 페이지
- `island.html` — 마음 체크와 잠깐 쉬어가기 등을 제공하는 페이지
- `robots.txt`, `sitemap.xml` — 크롤러 안내와 공개 URL 목록

## 현재 동작 범위

- 마음 체크 응답은 브라우저에서만 표시되며 저장되거나 전송되지 않습니다.
- 익명 게시판은 서버와 안전한 운영 절차가 연결되기 전까지 예시 화면입니다.
- 이 페이지는 전문 상담이나 치료를 대신하지 않습니다.
